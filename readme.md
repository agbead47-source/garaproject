# 개발요청서 분석·변환 도구 – UI 가안 (Flask)

> To-do 팀 화장품 무역 대시보드 중 **주제 3번** 기능의 UI 프로토타입.
> 이 파일을 프로젝트 루트에 두고, AI에게 "PLAN.md를 읽고 N단계만 진행해줘"처럼 단계별로 요청한다.

---

## 1. 기능 한 줄 요약
발주업체(해외 고객사)에게 받은 **개발요청서**를 업로드하면, 핵심 항목을 자동으로 뽑아내고
**연구소용 / 공장용** 내부 전달 문서로 나눠 변환하며, 원하는 **언어로 번역**해 주는 도구.

## 2. 이번 가안의 범위 (중요)
- **UI만 구현한다.** 실제 문서 분석, OCR, 번역, AI API 호출은 하지 않는다.
- 어떤 파일을 올려도 **미리 준비한 더미 분석 결과**를 보여준다.
- API 키, DB, 외부 네트워크 호출 **사용 금지**.
- `python app.py` 한 번으로 실행되고 http://127.0.0.1:5000 에서 확인 가능해야 한다.
- 나중에 실제 기능으로 교체할 자리는 함수로 분리하고 `# TODO: 실제 연동` 주석을 단다.

## 3. 기술 스택
- Python 3.10+, Flask (requirements.txt에는 `flask` 한 줄)
- Jinja2 템플릿 + 순수 CSS + 약간의 바닐라 JS
- 빌드 도구, 프론트엔드 프레임워크 사용하지 않음
- 아이콘이 필요하면 이모지 또는 CDN 사용

## 5. 공통 레이아웃 (base.html)

  - 📄 개발요청서 분석 (현재 기능, 활성 표시)
  - 🌍 국가별 규제 검색 (UI 가안, 12번 참고)
  - 📈 오늘의 트렌드 (UI 가안)
  - 🧪 AI 샘플 미리보기 (UI 가안)
  - 🗂 고객사 관리 (UI 가안)
  - 🕘 처리 이력
- 상단바: 현재 페이지 제목, 우측에 사용자명 "해외영업팀 홍길동" + 로그아웃
- 진행 단계 표시(스텝퍼): `① 업로드 → ② 분석 결과 → ③ 변환·번역` — 현재 단계 강조

## 6. 화면 상세

### 6-1. 문서 업로드 (`/`)
- 드래그앤드롭 업로드 박스 (PDF, DOCX, XLSX, JPG/PNG 안내 문구)
  - 파일을 올리면 파일명과 용량만 표시 (서버에서 내용은 사용하지 않음)
- **"샘플 개발요청서로 체험하기"** 버튼 (파일 없이도 진행 가능)
- 옵션 입력 영역
  - 고객사 선택: 드롭다운 (더미 고객사 목록)
  - 전달 대상: 체크박스 `연구소` / `공장` (기본 둘 다 체크)
  - 출력 언어: 드롭다운 `한국어(기본)` / `English` / `中文` / `Tiếng Việt`
- "분석 시작" 버튼 → 2초 로딩 화면("문서를 읽는 중… → 항목 추출 중…") 후 `/result` 로 이동
  - 로딩은 JS setTimeout으로 연출만 한다

### 6-2. 분석 결과 (`/result`)
- 상단 요약 카드 4개
  - 문서 언어 감지: English
  - 추출 항목 수: 14
  - 확인 필요 항목: 3 (주황색 강조)
  - 규제 주의 성분: 1 (빨간색 강조)
- 좌우 2단 구성
  - **왼쪽: 원문 미리보기** — 더미 영문 개발요청서 텍스트를 스크롤 박스로 표시
  - **오른쪽: 추출 항목 표** — 컬럼: `항목 | 추출 값 | 신뢰도 | 상태`
    - 신뢰도는 막대 또는 % 뱃지
    - 상태: `확인됨`(초록) / `확인 필요`(주황) / `누락`(회색)
    - 행을 클릭하면 왼쪽 원문에서 해당 문장에 형광펜 하이라이트 (JS)
    - 추출 값은 인라인 수정 가능 (input으로 전환, 저장은 화면에서만)
- 하단 "규제 체크 미리보기" 박스
  - 예: "Retinol 요청 농도가 EU 기준 초과 가능성 — 국가별 규제 검색에서 확인 필요"
  - 버튼 "규제 검색으로 이동"은 비활성 + 툴팁 "다른 팀원 파트 연동 예정"
- 하단 버튼: `이전` / `내부 전달 문서 만들기 →`

### 6-3. 내부 전달 문서 변환 (`/convert`)
- 탭 2개: **🧪 연구소용** / **🏭 공장용**
- 연구소용 문서 섹션
  - 제품 개요 (제품명, 유형, 타깃 국가)
  - 제형·사용감 요청 (텍스처, 향, 색상)
  - 필수 성분 / 배제 성분(Free-from) 목록
  - 인증·클레임 요구 (Vegan, Cruelty-free 등)
  - 시험 요청 (안정성, 피부자극 등)
  - 규제 주의사항
- 공장용 문서 섹션
  - 제품명, 용량, 용기·부자재 사양
  - MOQ, 목표 단가
  - 납기, 선적 조건
  - 포장·라벨 요구사항
- 우측 상단 **언어 전환 드롭다운** → 선택 시 문서 내용이 해당 언어 더미 텍스트로 교체
  (한국어, 영어는 실제 번역 문장으로 준비, 나머지 언어는 일부만 번역된 예시여도 됨)
- 원문 대비 보기 토글: 켜면 각 항목 아래에 원문 문장을 회색 작은 글씨로 표시
- 하단 액션 버튼 (모두 동작은 alert 또는 토스트 메시지로 대체)
  - 📋 복사하기 (실제로 클립보드 복사까지는 구현)
  - ⬇️ PDF 다운로드 → "가안에서는 지원하지 않습니다"
  - ✉️ 담당자에게 전달 → 모달에서 수신자(연구소 김연구 / 공장 박생산) 선택 후 "전달 완료" 토스트

### 6-4. 처리 이력 (`/history`)
- 필터: 기간, 고객사, 상태
- 표 컬럼: `접수일 | 고객사 | 문서명 | 원문 언어 | 전달 대상 | 상태 | 담당자`
- 상태 뱃지: `분석 완료` / `전달 완료` / `확인 필요`
- 행 클릭 시 `/result` 로 이동 (같은 더미 결과를 보여줘도 됨)
- 더미 데이터 6~8건

### 6-5. (선택) 로그인 (`/login`)
- 아이디/비밀번호 입력, 아무 값이나 입력하면 통과
- Flask `session`에 사용자명 저장, 로그아웃 시 삭제
- 로그인 안 하면 `/login` 으로 리다이렉트
- `app.secret_key` 는 코드에 임시 문자열로 넣고 주석으로 "가안용" 명시

## 10. 바이브코딩 진행 순서
한 번에 한 단계씩 요청하고, 매 단계마다 실행해서 화면을 확인한다.

1. requirements.txt, app.py, base.html, style.css → 사이드바와 상단바만 있는 빈 화면 띄우기
2. dummy_data.py 작성 (7번 내용 전부)
3. 업로드 화면(6-1) + 로딩 연출
4. 분석 결과 화면(6-2) — 표, 요약 카드까지
5. 분석 결과 화면의 원문 하이라이트, 인라인 수정 (app.js)
6. 변환 화면(6-3) — 탭, 언어 전환
7. 변환 화면의 복사/전달 모달/토스트
8. 처리 이력 화면(6-4)
9. (선택) 로그인(6-5)
10. 전체 디자인 다듬기 — 간격, 색, 스텝퍼 강조

### 12-1. 국가별 규제 검색 (`/regulation`)
- 필터: 성분명 검색, 판매 국가(미국·EU·중국·일본·베트남), 판정
- 요약 카드 3개: 검색 결과 / 주의 필요 / 사용 불가
- 표 컬럼: `국가 | 성분(INCI) | 요청 농도 | 허용 기준 | 판정`
  - 판정 뱃지: `적합`(초록) / `주의`(주황) / `사용 불가`(빨강)
  - 행을 클릭하면 근거 규정·성분 분류·최신 개정일·메모가 아래로 펼쳐진다
- 우측: 선택한 국가의 등록 제도·소요 기간·필요 서류·라벨 요구·주의사항
- 분석 결과의 규제 주의 성분(Retinol 0.5%)과 연결되는 카드

### 12-2. 오늘의 트렌드 (`/trends`)
- 카테고리 탭: 전체 / 스킨케어 / 선케어 / 메이크업 / 헤어·바디
- 요약 카드 4개: 급상승 키워드 / 신규 진입 / 관심 국가 / 분석 게시물 수
- 키워드 랭킹 표: 순위·전주 대비 변동(▲▼NEW), 언급량 막대, 증감률
  - "요청서 초안" 버튼은 토스트로 대체
- 우측: 성분 트렌드 증감률, 국가별 관심 카테고리, 시장 소식(경쟁사·규제·원료·채널)

### 12-3. AI 샘플 미리보기 (`/sample`)
- 개발요청서를 올리면(파일 없이 눌러도 됨) 3단계 로딩 연출 후 결과 화면
- 샘플 후보 3종 카드: 기본안 / EU 대응 저농도 레티날안 / 원가 절감안
  - 매칭률, 예상 원가, 리스크 뱃지 표시 · 카드를 누르면 아래 상세가 바뀐다
- 상세: 제형 정보(베이스·텍스처·pH·원가·일정), 주요 활성 성분표, 예상 처방표(상/원료/함량/역할)
- 우측: 예상 사용감 막대, 확인 필요 사항, 유사 양산 사례
- "연구소에 샘플 의뢰" / "처방표 다운로드"는 토스트로 대체

### 12-4. 고객사 관리 (`/customers`, `/customers/<id>`)
- 목록: 검색(회사명·바이어명·국가) + 등급 필터, 요약 카드 4개
  - 고객사 카드에 국기·등급·바이어 연락처·특징 태그·누적 발주/진행 중/요청사항/평균 회신
- 상세 상단: 담당 바이어 정보, 거래 현황, 특징 태그, 최근 연락
